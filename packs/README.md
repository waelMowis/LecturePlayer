# حزم السبورة العلمية في «مسار»

هذه الملفات **ليست داخل المثبّت**. يُنزّلها «مسار» عند أول استخدام (عبر `/scipack/` في القارئ) ويحفظها على الجهاز.

| المجلد | المحتوى | الترخيص |
|---|---|---|
| `thumbs/v1` | صور مصغرة لفهرس مكتبة الرسوم (من Bioicons وHealth Icons) | ترخيص كل رسم في `Reader/lib/sci/library.json` |
| `ketcher/v3.21` | محرر الجزيئات Ketcher 3.21 مبنيًا (EPAM) | Apache-2.0 |
| `rayoptics/v5.5` | محاكي البصريات Ray Optics Simulation 5.5 مبنيًا (Yi-Ting Tu وآخرون) | Apache-2.0 |

الرسوم نفسها تُنزَّل من مستودعاتها الأصلية بأرقام commit ثابتة:
Bioicons (duerrsimon/bioicons) وHealth Icons (resolvetosavelives/healthicons).
